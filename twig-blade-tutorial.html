1Twig: Include Template · 包含模板

English · 原文
  • You can include other templates to reduce duplicated content.

The shared header (logo, menu, site intro) is saved once in _header.html.twig, then every page simply includes it with {{ include('_header.html.twig') }}.

中文 · 翻译

2Twig: Template Inheritance — Base · 模板继承：基础模板

English · 原文
  • Template inheritance involves creating a base template with all the content shared by a group of web pages, then creating individual child templates that extend the base template.
  • The Twig base template is a complete HTML page in its own right, although it may have default or empty blocks meant to be overridden in the child templates.
中文 · 翻译
  • 模板继承是指：先创建一个基础模板（base），包含一组网页所共享的全部内容；然后再创建各个子模板（child），去扩展（extend）这个基础模板。
  • Twig 的基础模板本身就是一个完整的 HTML 页面，只是其中可能带有一些「默认内容」或「空白的 block（块）」，这些块留给子模板去覆盖。
twigtemplates/base.html.twig（基础模板） 
{# 基础模板：完整 HTML 页面 + 留给子模板覆盖的 block #}
<!doctype html>
<html lang="en">
<head>
    <title>MGW: {{ pageTitle }}</title>
</head>
<body>
    <header>
        <img src="/images/logo.png" alt="logo" width="200px">
        <ul>
            <li><a href="/">Home</a></li>
            <li><a href="/?action=contact">Contact Us</a></li>
        </ul>
    </header>

    <blockquote>
        <p>
            <b>MGW.</b>
            <br>You know it makes sense!
        </p>
        <p>
            Welcome to My Great Website (MGW).
        </p>
    </blockquote>

    <h1>{{ pageTitle }}</h1>

    {# 空的 main 块：由子模板填充 #}
    {% block main %}
    {% endblock %}
</body>
</html>

3Twig: Template Inheritance — Child · 模板继承：子模板

English · 原文
  • The child template will fill in or override the base template with their unique content.

The child starts with {% extends 'base.html.twig' %} and only writes the blocks it wants to change — everything else is inherited from the base.

中文 · 翻译
  • 子模板会用自己的独有内容去「填充」或「覆盖」基础模板中对应的块。

子模板以 {% extends 'base.html.twig' %} 开头，只需写出自己要修改的 block，其余内容全部继承自基础模板。

    <p>
        Contact us as follows:
    </p>

        <dt>Email</dt>

        <dt>Phone</dt>
        <dd>+123 22-333-4444</dd>

        <dt>Address</dt>

{% endblock %}

4Twig: Sandbox 与关注点分离 · Sandbox and Separation of Concern

English · 原文
  • In Twig, all functions and filters calls are restricted by the functions you explicitly enable (besides the built-in functions).
  • The template designer cannot easily take shortcuts, e.g., calling a query in your templates. The query result needs to be passed to the view.
  • It may lead to more work to just call a simple function/filter sometimes.
  • Separation of concern between the model and the view.
  • Twig also includes a Sandbox mode, which can create a safe context, e.g., to let users edit their templates, with limited access to functions/variables. These templates can also be retrieved from a database.
中文 · 翻译
  • 在 Twig 中，所有函数和过滤器的调用都受限于你「显式启用」的函数（内置函数除外）。
  • 模板设计者不能轻易「走捷径」，例如在模板里直接调用数据库查询。查询结果必须先传递给视图。
  • 有时，哪怕只是调用一个简单的函数/过滤器，也要多做不少工作。
  • 这实现了模型（Model）与视图（View）之间的关注点分离。
  • Twig 还提供沙箱（Sandbox）模式：可以创建一个安全的上下文，例如允许用户编辑自己的模板，但只赋予其受限的函数/变量访问权限。这类模板也可以存放在数据库中、需要时再取出。

5Using Twig · 使用 Twig：Environment 与 render()

English · 原文
  • We need to tell Composer that we require the twig package.
  • Our code will need the Twig\Environment class, especially its render() method, which requires us to specify the template file name — usually <pageName>.html.twig by convention — and arguments: an array variable containing the data used to customize the template.
中文 · 翻译
  • 我们需要告诉 Composer：项目需要 twig 包。
  • 代码中需要用到 Twig\Environment 类，尤其是它的 render() 方法。调用 render() 时需要指定：模板文件名（按惯例通常命名为 <pageName>.html.twig），以及参数（arguments）—— 一个数组变量，其中存放用于定制模板的数据。
phprender() 的典型用法 
<?php
// 1. 模板文件名（按惯例通常为 <pageName>.html.twig）
$template = 'path/templateName.html.twig';

// 2. 参数：一个数组，键 = Twig 模板中使用的变量名，值 = PHP 变量
$args = [
    'variable1NameForTwig' => $phpVariable1,
    'variable2NameForTwig' => $phpVariable2,
];

// 3. 渲染模板得到 HTML，并输出到页面
$html = $this->twig->render($template, $args);
print $html;

6Twig: Application 类 · Application Class 与入口文件

English · 原文
  • An Application class is created to initialize the Twig environment and provide the run() method to render the page.
  • The index file only requires the Composer autoloader, then creates an Application and calls run().
中文 · 翻译
  • 我们创建一个 Application 类，用于初始化 Twig 环境，并提供 run() 方法来渲染页面。
  • 入口文件 index.php 只需加载 Composer 自动加载器，然后实例化 Application 并调用 run()。
phpsrc/Application.php 
<?php
namespace Mattsmithdev;

use Twig\Loader\FilesystemLoader;
use Twig\Environment;

class Application
{
    const PATH_TO_TEMPLATES = __DIR__ . '/../templates';

    private Environment $twig;

    public function __construct()
    {
        // 初始化 Twig：指定模板所在的目录
        $loader = new FilesystemLoader(self::PATH_TO_TEMPLATES);
        $this->twig = new Environment($loader);
    }

    public function run()
    {
        $meals = [
            'breakfast' => 'toast',
            'lunch'     => 'salad',
            'dinner'    => 'fish and chips',
        ];

        $product1 = new Product();
        $product1->setDescription('bag of nails');
        $product1->setPrice(18.99);

        $template = 'demo.html.twig';
        $args = [
            'name'    => 'matt',
            'meals'   => $meals,
            'product' => $product1,
        ];

        $html = $this->twig->render($template, $args);
        print $html;
    }
}
phppublic/index.php（入口） 
<?php
require_once __DIR__ . '/../vendor/autoload.php';

use Mattsmithdev\Application;

$app = new Application();
$app->run();
twigtemplates/demo.html.twig 
<!doctype html>
<html lang="en">
<head>
    <title>Twig examples</title>
</head>
<body>
    <p>Hello {{ name }}</p>
    <hr>

    <hr>

        {{ dump(product) }}

7环境准备：cd 进入文件夹与安装 Composer · Setup: cd & Composer（Windows cmd / macOS Terminal）

English · 原文
  • Open a terminal:
    • Windows: press Win + R, type cmd and press Enter (or search "Command Prompt" in the Start menu).
    • macOS: open Terminal via Spotlight (Cmd + Space, type "Terminal").
  • Use cd (change directory) to enter your project folder. Windows paths use backslash \; macOS paths use forward slash /, and ~ means your home folder.
  • List the folder contents with dir (Windows) or ls (macOS) to confirm you are in the right place; cd .. goes up one level.
  • Install Composer (the dependency manager for PHP):
    • Windows: download and run Composer-Setup.exe from getcomposer.org — it locates your PHP automatically; reopen cmd after installing.
    • macOS: install with Homebrew (brew install composer) or the official installer script.
  • Verify with composer --version and php -v, then install the Twig component and run the project from the folder that contains composer.json / index.php.

9Twig vs Blade · 两种模板引擎对比

English · 原文
  • Blade is another template engine that offers slightly faster performance, less functionality, but simpler syntax that is great for rapid development.
  • Unlike Twig — which is part of the Symfony framework and quite flexible to be used in other frameworks (except Laravel) and larger projects — Blade is used only in Laravel.
  • Blade templates allow PHP code to be written within the template.
  • Less strict on separation of concern.
  • Less secure than Twig.
中文 · 翻译
  • Blade 是另一个模板引擎：性能略快、功能较少，但语法更简单，非常适合快速开发。
  • Twig 是 Symfony 框架的一部分，非常灵活，可用于其他框架（Laravel 除外）和大型项目；而 Blade 只用于 Laravel。
  • Blade 模板允许在模板中直接编写 PHP 代码。
  • 对关注点分离（separation of concern）的要求较宽松。
  • 安全性不如 Twig。
对比维度TwigBlade
性能稍慢略快（slightly faster）
功能更丰富（过滤器、沙箱等）较少
语法较严格更简单，适合快速开发
框架支持Symfony 的一部分；可用于其他框架（除 Laravel）及大型项目仅用于 Laravel
模板中写 PHP不允许允许
关注点分离更严格较宽松
安全性更安全（自动转义、Sandbox）相对较弱

10Blade 模板引擎：基础语法 · Blade Basics

English · 原文
  • Blade supports template inheritance and control structures that are simpler to write. It has @section that is similar to block in Twig.
  • Blade can display variables in escaped content {{ $var }} or raw without filter {!! $var !!}.
  • Accessing an object's member in Blade is similar to PHP (e.g. $user->name).
中文 · 翻译
  • Blade 支持模板继承和控制结构，写法更简单。它的 @section 类似于 Twig 中的 block。
  • Blade 既可以用转义方式输出变量 {{ $var }}，也可以用不做过滤的原样输出 {!! $var !!}。
  • 在 Blade 中访问对象成员的方式与 PHP 类似（如 $user->name）。
blade继承 + 循环控制结构 
@extends('layouts.master')

@section('content')
    @foreach ($users as $user)
        <p>This is user {{ $user->name }}</p>
    @endforeach
@endsection
blade条件判断与两种输出方式 
@if ($user)
    <p>Welcome, {{ $user->name }}</p>
@else
    <p>Welcome, Guest</p>
@endif

{{-- 转义输出（推荐） --}}
{{ $var }}

{{-- 原样输出，不经过转义过滤（谨慎使用） --}}
{!! $var !!}

11Blade 模板引擎：命名与布局继承 · File Naming & Master Layout

English · 原文
  • The Blade file is named as filename.blade.php by convention.
  • The master Blade (similar to the base template of Twig) is usually placed in the main layouts folder.
  • The child template extends the master layout by specifying the combination of folder structure and template filename. For example, extend:
    • layouts.master for layouts/master.blade.php
    • layouts.main.home for layouts/main/home.blade.php
中文 · 翻译
  • 按照惯例，Blade 文件命名为 文件名.blade.php。
  • 主模板（master，类似 Twig 的基础模板）通常放在主 layouts 文件夹中。
  • 子模板通过「文件夹结构 + 模板文件名」的点号组合来扩展主布局。例如：
    • layouts.master 对应 layouts/master.blade.php
    • layouts.main.home 对应 layouts/main/home.blade.php
bladelayouts/master.blade.php（主布局） 
<!-- layouts/master.blade.php -->
<html>
    <head>
        <title>App Name - @yield('title')</title>
    </head>
    <body>
        @section('sidebar')
            This is the master sidebar.
        @show

        <div class="container">
            @yield('content')
        </div>
    </body>
</html>
bladechild.blade.php（子模板） 
<!-- child.blade.php -->
@extends('layouts.master')

@section('title', 'Page Title')

@section('sidebar')
    @parent

    <p>This is appended to the master sidebar.</p>
@endsection

@section('content')
    <p>This is my body content.</p>
@endsection
